# Ansible

Config management for the homelab. `inventory/homelab.ini` covers the k3s lab;
`inventory/kubeadm.ini` is generated by terraform from the node map, pins SSH
host keys via `inventory/known_hosts`, and must not be edited by hand.

## Bootstrap the kubeadm cluster

Prerequisites:

```bash
ansible-galaxy collection install -r requirements.yml
../scripts/kubeadm-known-hosts.sh   # after the VMs are up, pins their host keys
```

Then bootstrap the whole cluster with one command:

```bash
ansible-playbook -i inventory/kubeadm.ini playbooks/kubeadm-bootstrap.yml
```

The playbook runs three plays: common node preparation (`k8s_common`),
control-plane init with Calico (`k8s_control`), then the workers joining one
at a time (`k8s_worker`, `serial: 1`).

## Adding a worker

Bump `worker_count` in `terraform-kubeadm` and apply, pin the new host key
with `../scripts/kubeadm-known-hosts.sh`, then re-run only the worker play:

```bash
ansible-playbook -i inventory/kubeadm.ini playbooks/kubeadm-bootstrap.yml --tags workers
```
